# Phase 1 – Brainstorming & Ideation

## 1.1 Project Title

**Auto Ticket Classification Using Flow Designer**

---

## 1.2 Project Background

The school IT helpdesk receives multiple support requests from students and teachers every day. These requests may be related to Wi-Fi connectivity, projector failures, password problems, and slow computers.

Currently, IT staff manually review each request and identify the appropriate category and subcategory.

This manual classification process requires additional effort and may become difficult to manage when the number of support requests increases.

---

## 1.3 Problem Identification

The major problem identified is the manual classification of IT support tickets.

IT staff are required to:

* Review the ticket description.
* Identify the type of issue.
* Select the appropriate category.
* Select the appropriate subcategory.
* Inform the caller about ticket creation.

This process can be time-consuming and error-prone.

---

## 1.4 Proposed Solution

The proposed solution is to implement an automated ticket classification system using **ServiceNow Flow Designer**.

The system analyzes predefined keywords in the ticket's short description and automatically assigns the appropriate Category and Subcategory.

For example:

| Keyword / Issue  | Category    | Subcategory     |
| ---------------- | ----------- | --------------- |
| WiFi / Network   | Network     | Wi-Fi           |
| Projector        | Hardware    | Projector       |
| Password / Login | Access      | Forgot Password |
| Slow / Hanging   | Performance | Slow Computer   |

---

## 1.5 Project Objectives

The objectives of the proposed system are:

1. Automatically classify incidents when they are created.
2. Reduce manual effort for IT support staff.
3. Automatically assign Category and Subcategory.
4. Improve ticket routing efficiency.
5. Maintain structured and standardized ticket information.
6. Send an automated email notification to the caller.
7. Provide an easily maintainable no-code solution.

---

## 1.6 Expected Benefits

The proposed system is expected to:

* Reduce repetitive manual work.
* Improve consistency in ticket classification.
* Provide structured ticket information.
* Improve the efficiency of ticket handling.
* Provide immediate confirmation to the caller.
* Support future scalability.

---

## 1.7 Ideation Outcome

The brainstorming and ideation phase resulted in the selection of **Auto Ticket Classification Using Flow Designer** as the project solution.

The project uses ServiceNow Flow Designer to automate classification without requiring complex scripting or machine-learning implementation.
